# 阅读器：把正文排成一本可以翻的书

**日期**：2026-10-29
**上游**：`2026-10-28-multi-agent-ux-slice4-design.md`（共创页与写作页已稳定）
**目标**：作者写完的正文要能像一本书一样被读——不是「预览框」，是能翻页、能沉浸、记得住读到哪的书页。

---

## 1. 一句话

新增「阅读」模块：正文以暖纸 + 衬线 + 真分页呈现，桌面双页对开、窄屏单页滚动；键盘可翻、目录可跳、位置可续。

## 2. 数据与边界

- 只用现有接口：`GET /book`（书名 / 章名 / 字数 / 状态）与 `GET /chapters/:n/text`（已拼好的段落，`\n\n` 分段）。
- **不改后端、不新增依赖**。
- 只有 `finalized` 与有正文的章会出现在「可读」列表；空章仍可在目录里看到，但翻开是空态。

## 3. 视觉

- 纸 `#FBF8F1`，墨 `#2B2723`，次要 `#6F685E`，界行 `#E4DCCF`，强调墨绿 `#3F5D4B`。
- 正文衬线（复用 `--font-serif`），17px / 行高 1.95 / 首行缩进 2em / 行宽 28–32 字。
- 双页对开：两页平铺在暖灰桌面（`#EFEAE1`）上，中缝一条淡阴影；**不做 3D 卷曲**。
- 章扉页：整页只放「第一章 / 章名 / 一句 summary（取自章摘要，没有就不放）/ 细线」。
- 页眉：左页书名、右页章名；页脚：外侧页码；未定稿章在页脚加一个「草稿」小点。

## 4. 分页算法（唯一有技术风险的地方）

用 CSS multi-column 让浏览器断行，不自己切中文：

- 文本块：`column-width = 页宽 - 2×页边距`，`column-gap = 2×页边距 + 中缝`，`height = 页高 - 2×纵向页边距`，`column-fill: auto`。
- 列数 `N = ceil((scrollWidth - 1) / (colW + gap))`；每屏展示 2 列，屏数 `= ceil(N / 2)`。
- 翻屏：`translateX(-2 × spread × (colW + gap))`。
- 章扉页是文本流里的一个 `height: 页高` 块 + `break-after: column`，所以它天然独占第一列，正文从第二列开始。
- 重算时机：`ResizeObserver`、`document.fonts.ready`、字号变化。重排后按比例还原屏号。

## 5. 交互

| 操作 | 键 |
|---|---|
| 翻页 | ← → / PgUp PgDn / 空格（Shift+空格 回退） |
| 章首 / 章尾 | Home / End（End 停在「下一章」卡片） |
| 目录 | `c`，抽屉内 ↑↓ + Enter |
| 沉浸 | `f`，Esc 退出 |
| 退出目录 | Esc |

- 位置记忆：`localStorage: inkloom.read.<bookId>` = `{ chapterNo, spread }`，按比例还原。
- 字号 A− / A+ 四档（15 / 16.5 / 18 / 19.5 / 21px）。
- `prefers-reduced-motion: reduce` 时翻页不做位移动画。
- `aria-live="polite"` 播报「第 X 页，共 Y 页」。

## 6. 不做

3D 纸张卷曲、划线笔记、朗读、EPUB 导出、竖排双栏（需要重做分页与 `writing-mode`）。

## 7. 验收

1. 1440×900：双页对开，扉页在左、正文从右页开始，页码与页眉正确。
2. 1024 与 375：单页滚动，无横向溢出。
3. 键盘：←/→/空格/Home/End/`c`/`f` 全部可用；目录可用方向键选择。
4. 刷新后回到上次的章与屏；改字号后位置按比例保留。
5. `prefers-reduced-motion` 下无位移动画。
