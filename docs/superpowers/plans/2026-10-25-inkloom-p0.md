# inkloom P0 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建成 inkloom 的数据底座——书文件夹、要素 append-only 版本、四种回退、可重建索引、Git 版本管理，全部通过 CLI/API 验收，不含任何 AI 调用。

**Architecture:** 四层单向依赖 `shared → core → prompt/api → web`。`core` 零 IO，全部是纯函数（可 100% 单测）；`apps/api` 是唯一有副作用的地方（文件系统 / SQLite 索引 / Git 子进程）。文件是唯一事实源，SQLite 只是可丢弃的查询索引，`reindex` 能从文件完全重建。

**Tech Stack:** Node 24 + pnpm 11 workspace · TypeScript strict · Zod · Hono · Prisma + SQLite · Vitest · Biome

**Spec:** `docs/superpowers/specs/2026-10-25-inkloom-design.md`（2367 行，执行时必须对照阅读，尤其 §2.6 数据一致性与并发契约、§2.7 正文文件格式契约）

## Global Constraints

以下约束对**每个任务**都生效，不再逐条重复：

| 约束 | 值 / 规则 | 出处 |
|---|---|---|
| Node 版本 | `>=24`（实测 24.16.0） | 环境实测 |
| 包管理器 | `pnpm@11.6.0`，workspace | 环境实测 |
| TS 严格度 | `strict` + `noUncheckedIndexedAccess` + `exactOptionalPropertyTypes` | spec §9.1 |
| Lint/Format | **Biome**（不用 ESLint + Prettier） | spec §9.1 |
| 单文件行数 | >300 行 warning，>500 行 CI failure | spec §9.2 |
| `core` 覆盖率 | **>80%** | spec §8.1 |
| `core` 禁止依赖 | `fs` / `node:fs` / `fetch` / `prisma` / `hono` | spec §2.1 |
| 正文写入 | **永不写 `EntityRevision`**；正文历史只归 Git | ADR-27 |
| 要素写入 | append-only：**永不 UPDATE / DELETE**，只追加 revision | P0-9 |
| 并发 | **所有写操作走单一队列**，生成可并行、落库不可 | P0-21 |
| 文件写入 | 先 CAS 校验 contentHash → tmp → fsync → rename | §2.6 |
| 段标记 | `<!-- seg:XXXX -->`，**4 位 base36**，全书唯一永不复用 | §2.7 |
| 场景边界 | 候选稿 `<!-- scene:N v:M -->`；定稿 `<!-- scene:N -->` | §2.7 |
| Commit | Conventional Commits（`feat:` `fix:` `test:` `chore:` `docs:`） | spec §9.4 |
| 路径风格 | 代码内统一 POSIX `/`，仅在调用 `fs` 时用 `node:path` 转换 | 本计划约定 |
| 错误风格 | 领域错误用 `Result<T, E>` 或抛 `InkloomError`（带 `code` 字段），不用裸 `Error` | 本计划约定 |

### P0 范围决策（三条，执行前需知晓）

1. **P0 不做 UI。** 验收通过 CLI 与 API 完成。理由：P0 的验收点（四种回退、reindex 幂等、CAS 冲突、checkpoint 同点回退）全是边界行为，UI 无法证明其正确性；而 P1 的写作页需要完整交互，与 P0 的列表页没有复用价值，先做会做两遍。
2. **P0 不接 LLM。** `prompt` 包与 `llm` 适配器整体推迟到 P1。P0 的正文通过手工写入（API/CLI）产生，用于验证文件契约与回退。
3. **P0 建全部 19 张表，但只实现 15 张的读写。** 一次迁移到位，避免 P1 反复改 schema。未实现读写的 4 张：`Asset` / `GenerationRun` / `QualityReview` / `PromptTemplate`。

- [ ] **Step 5: 写依赖方向检查脚本（关键——这是"core 零 IO"的唯一强制手段）**

`scripts/check-deps.mjs`：
```js
#!/usr/bin/env node
// 扫描 packages/core 下所有 .ts 的 import，禁止 IO/DB/HTTP。
// 违规则打印证据并 exit 1。
import { readdirSync, readFileSync, statSync } from 'node:fs'
import { join, relative } from 'node:path'

const CORE_DIR = 'packages/core/src'
const BANNED = ['fs', 'node:fs', 'fs/promises', 'node:fs/promises', 'prisma',
  '@prisma/client', 'hono', 'node:child_process', 'node:net', 'node:http']

function walk(dir) {
  const out = []
  for (const name of readdirSync(dir)) {
    const p = join(dir, name)
    if (statSync(p).isDirectory()) out.push(...walk(p))
    else if (p.endsWith('.ts')) out.push(p)
  }
  return out
}

const violations = []
for (const file of walk(CORE_DIR)) {
  const src = readFileSync(file, 'utf8')
  const re = /(?:from|import)\s*\(?\s*['"]([^'"]+)['"]/g
  let m
  while ((m = re.exec(src)) !== null) {
    const spec = m[1]
    if (BANNED.some((b) => spec === b || spec.startsWith(`${b}/`))) {
      const line = src.slice(0, m.index).split('\n').length
      violations.push(`${relative(process.cwd(), file)}:${line}  禁止导入 '${spec}'`)
    }
  }
}

if (violations.length > 0) {
  console.error('✗ core 层出现 IO 依赖（spec §2.1 铁律）：')
  for (const v of violations) console.error(`  ${v}`)
  process.exit(1)
}
console.log('✓ core 层无 IO 依赖')
```

```ts
export type ErrorCode =
  | 'NOT_FOUND'
  | 'CONFLICT'
  | 'INVALID_INPUT'
  | 'CORE_IO_VIOLATION'
  | 'CAS_MISMATCH'
  | 'SEG_NOT_FOUND'
  | 'GIT_FAILED'
  | 'INDEX_STALE'

export class InkloomError extends Error {
  readonly code: ErrorCode
  constructor(code: ErrorCode, message: string) {
    super(message)
    this.name = 'InkloomError'
    this.code = code
  }
}
```

```ts
import { InkloomError } from '@inkloom/shared'

export interface SceneSegment {
  segId: string
  text: string
}

export interface SceneFile {
  sceneNo: number
  version: number
  segments: SceneSegment[]
}

export interface ChapterScene {
  sceneNo: number
  text: string
}

export interface ChapterFile {
  title: string
  scenes: ChapterScene[]
}

const SCENE_HEADER_RE = /^<!--\s*scene:(\d+)\s+v:(\d+)\s*-->\s*$/
const SEG_MARKER_RE = /^<!--\s*seg:([0-9a-z]{4})\s*-->\s*$/
const CHAPTER_SCENE_RE = /^<!--\s*scene:(\d+)\s*-->\s*$/
const CHAPTER_TITLE_RE = /^#\s+(.+?)\s*$/

/** 按空行切分段落，丢弃空段（§2.7 六：段内容边界以空行为界） */
export function splitParagraphs(text: string): string[] {
  return text
    .split(/\r?\n\s*\r?\n/)
    .map((p) => p.trim())
    .filter((p) => p.length > 0)
}

/**
 * 解析候选稿场景文件（§2.7 一）。
 * 格式：首行场景头，随后若干 (段标记 + 段文本) 组。
 * 违规一律抛 INVALID_INPUT —— 宁可拒绝，也不要静默产出错段。
 */
export function parseSceneFile(raw: string): SceneFile {
  const lines = raw.split(/\r?\n/)
  const firstLine = lines[0] ?? ''
  const header = SCENE_HEADER_RE.exec(firstLine)
  if (!header) {
    throw new InkloomError('INVALID_INPUT', `场景文件缺少合法场景头: ${firstLine.slice(0, 60)}`)
  }
  const sceneNo = Number(header[1])
  const version = Number(header[2])

  const segments: SceneSegment[] = []
  const seen = new Set<string>()
  let currentId: string | null = null
  let buffer: string[] = []

  const flush = (): void => {
    if (currentId === null) return
    const text = buffer.join('\n').trim()
    if (text.length > 0) segments.push({ segId: currentId, text })
    buffer = []
  }

  for (const line of lines.slice(1)) {
    const m = SEG_MARKER_RE.exec(line)
    if (m) {
      flush()
      const segId = m[1] as string
      if (seen.has(segId)) {
        throw new InkloomError('INVALID_INPUT', `段 ID 重复: ${segId}`)
      }
      seen.add(segId)
      currentId = segId
      continue
    }
    if (currentId !== null) buffer.push(line)
  }
  flush()

  return { sceneNo, version, segments }
}

/** 序列化候选稿场景文件（§2.7 一），与 parseSceneFile 严格互逆 */
export function serializeSceneFile(scene: SceneFile): string {
  const parts: string[] = [`<!-- scene:${scene.sceneNo} v:${scene.version} -->`]
  for (const seg of scene.segments) {
    parts.push(`<!-- seg:${seg.segId} -->`, seg.text.trim())
  }
  return `${parts.join('\n').replace(/\n<!-- seg:/g, '\n\n<!-- seg:')}\n`
}

/** 解析定稿章文件（§2.7 二）：一级标题 + 若干 (场景边界 + 正文) */
export function parseChapterFile(raw: string): ChapterFile {
  const lines = raw.split(/\r?\n/)
  let title: string | null = null
  const scenes: ChapterScene[] = []
  let currentScene: number | null = null
  let buffer: string[] = []

  const flush = (): void => {
    if (currentScene === null) return
    const text = buffer.join('\n').trim()
    scenes.push({ sceneNo: currentScene, text })
    buffer = []
  }

  for (const line of lines) {
    if (title === null) {
      const t = CHAPTER_TITLE_RE.exec(line)
      if (t) {
        title = (t[1] as string).trim()
        continue
      }
      if (line.trim().length > 0) {
        throw new InkloomError('INVALID_INPUT', '定稿文件首个非空行必须是一级标题')
      }
      continue
    }
    const m = CHAPTER_SCENE_RE.exec(line)
    if (m) {
      flush()
      currentScene = Number(m[1])
      continue
    }
    if (currentScene !== null) buffer.push(line)
  }
  flush()

  if (title === null) {
    throw new InkloomError('INVALID_INPUT', '定稿文件缺少一级标题')
  }
  return { title, scenes }
}

/** 序列化定稿章文件（§2.7 二） */
export function serializeChapterFile(chapter: ChapterFile): string {
  const parts: string[] = [`# ${chapter.title}`]
  for (const s of chapter.scenes) {
    parts.push(`<!-- scene:${s.sceneNo} -->`, s.text.trim())
  }
  return `${parts.join('\n').replace(/\n<!-- scene:/g, '\n\n<!-- scene:')}\n`
}
```

> ⚠️ 实现注意：`serializeSceneFile` 里用 `replace` 在标记前补空行，是为了段间以空行分隔（§2.7 示例格式）。如果你觉得这行太"技巧化"，可以改成在 `parts.push` 时直接拼 `\n` 前缀——两种写法等价，但**必须保证 `parse(serialize(x)) === x` 的测试通过**。

```ts
const MARKER_RE = /<!--[\s\S]*?-->/g
const CJK_RE = /[\u3400-\u4dbf\u4e00-\u9fff\uf900-\ufaff]/g
const LATIN_RE = /[A-Za-z]/g
const DIGIT_RE = /[0-9]/g

/**
 * 字数口径（spec §2.7 六）：
 *   汉字 + 英文**字母** + 数字，各计 1；忽略标记、空白、标点。
 * 说明：英文按字母而非单词计，是 spec 的字面约定。
 * 若将来发现英文占比高的书统计偏大，改口径必须同步修改 spec §2.7 六，
 * 不允许只改代码。
 */
export function countWords(text: string): number {
  const stripped = text.replace(MARKER_RE, '')
  const cjk = stripped.match(CJK_RE)?.length ?? 0
  const latin = stripped.match(LATIN_RE)?.length ?? 0
  const digits = stripped.match(DIGIT_RE)?.length ?? 0
  return cjk + latin + digits
}
```

```ts
import { InkloomError } from '@inkloom/shared'

const ALPHABET = '0123456789abcdefghijklmnopqrstuvwxyz'
const SEG_ID_LEN = 4
const MAX_ATTEMPTS = 1000

export type RandomSource = () => number

/**
 * 生成段 ID（spec §2.7 一）：4 位 base36，全书唯一且永不复用。
 * 4 位 = 36^4 = 1,679,616 个值。3 位只有 46,656，300 章的书改稿后会耗尽。
 * 随机源注入是为了让测试确定性——生产环境传 Math.random。
 */
export function newSegId(rand: RandomSource, taken: ReadonlySet<string>): string {
  for (let attempt = 0; attempt < MAX_ATTEMPTS; attempt++) {
    let id = ''
    for (let i = 0; i < SEG_ID_LEN; i++) {
      const index = Math.floor(rand() * ALPHABET.length)
      id += ALPHABET[Math.min(index, ALPHABET.length - 1)]
    }
    if (!taken.has(id)) return id
  }
  throw new InkloomError('CONFLICT', '段 ID 空间接近耗尽，请检查是否重复使用了同一随机源')
}

/** 汇总一批场景文件里已占用的段 ID */
export function collectSegIds(files: { segments: { segId: string }[] }[]): Set<string> {
  const set = new Set<string>()
  for (const f of files) for (const s of f.segments) set.add(s.segId)
  return set
}
```

```ts
export interface NextRevisionInput {
  id: string
  entityType: EntityType
  entityId: string

  payload: unknown
  changeSource: ChangeSource
  changeReason?: string
  generationRunId?: string
  now: string

/**
 * 计算下一条 revision（spec §3.1 / ADR-27）。
 * 铁律：只追加，不修改。version 单调递增，parentRevisionId 形成链。
 * 注意：正文（draft_segment）不在此列——正文历史归 Git，见 ADR-27。

export function nextRevision(input: NextRevisionInput): RevisionRecord {
  const { prev } = input
  return {
    id: input.id,
    entityType: input.entityType,
    entityId: input.entityId,
    version: prev === null ? 1 : prev.version + 1,
    parentRevisionId: prev === null ? null : prev.id,
    payload: JSON.stringify(input.payload),
    changeSource: input.changeSource,
    changeReason: input.changeReason ?? null,
    generationRunId: input.generationRunId ?? null,
    createdAt: input.now,
  }
}
```

```ts
import type { CharacterStateSnapshot, EntityType, RevisionRecord } from './types.js'

function parsePayload(r: RevisionRecord): Record<string, unknown> {
  try {
    const v: unknown = JSON.parse(r.payload)
    return typeof v === 'object' && v !== null ? (v as Record<string, unknown>) : {}
  } catch {
    return {}
  }
}

/** 取实体最新版本（按 version 最大）。用于要素的“当前值”。 */
export function resolveLatest<T>(
  revisions: RevisionRecord[],
  entityType: EntityType,
  entityId: string,
): T | null {
  let best: RevisionRecord | null = null
  for (const r of revisions) {
    if (r.entityType !== entityType || r.entityId !== entityId) continue
    if (best === null || r.version > best.version) best = r
  }
  return best === null ? null : (parsePayload(best) as T)
}

/**
 * 推导角色在第 N 章时的状态（spec §4.8）。
 *
 * ★ 关键：按 payload.stateChapter 排序，**不是**按 version 排序。
 * 理由（ADR-13）：人可能回头补写第 3 章，此时最新 version 对应的却是第 3 章的状态，
 * 用它去写第 10 章会直接导致人物状态错乱。
 *
 * 同 stateChapter 时取 version 更大的（同一章的多次修订）。
 * 无匹配（角色尚未入场）返回 null。
 */
export function resolveCharacterState(
  revisions: RevisionRecord[],
  characterId: string,
  chapterNo: number,
): CharacterStateSnapshot | null {
  let best: RevisionRecord | null = null
  let bestStateChapter = -1

  for (const r of revisions) {
    if (r.entityType !== 'character' || r.entityId !== characterId) continue
    const payload = parsePayload(r)
    const sc = payload['stateChapter']
    if (typeof sc !== 'number' || sc > chapterNo) continue
    if (sc > bestStateChapter || (sc === bestStateChapter && (best === null || r.version > best.version))) {
      best = r
      bestStateChapter = sc
    }
  }

  if (best === null) return null
  const state = parsePayload(best)
  return {
    stateChapter: bestStateChapter,
    revisionId: best.id,
    stale: state['stateStale'] === true,
    state,
  }
}
```

```ts
import { InkloomError } from '@inkloom/shared'
import type { SceneFile } from '../text/markers.js'

export interface SegmentRollbackResult {
  scene: SceneFile
  previousText: string
  restoredText: string
}

/**
 * 单段回退（spec §2.7 四）。
 *
 * 语义：从历史版本里取出 segId 对应段的内容，替换当前版本里同名段的内容。
 * 其余段、段顺序、段 ID 一律不动。
 *
 * ★ 纯函数，不产生新版本号。调用方负责：
 *   1. 用返回的 scene 序列化，写成 v{latest+1}.md（**不覆盖旧版本**）
 *   2. 更新索引里的 contentHash
 *   3. 记一条 changeSource='rollback'（若回退的是要素）或 git commit（若回退的是正文）
 *
 * 边界：目标段在任一侧不存在 → SEG_NOT_FOUND。
 * 不支持的场景（YAGNI）：恢复已删除的段（这是插入，不是回退）。
 */
export function rollbackSegment(
  current: SceneFile,
  history: SceneFile,
  segId: string,
): SegmentRollbackResult {
  const currentSeg = current.segments.find((s) => s.segId === segId)
  const historySeg = history.segments.find((s) => s.segId === segId)

  if (currentSeg === undefined) {
    throw new InkloomError('SEG_NOT_FOUND', `当前版本（v${current.version}）中不存在段 ${segId}`)
  }
  if (historySeg === undefined) {
    throw new InkloomError('SEG_NOT_FOUND', `历史版本（v${history.version}）中不存在段 ${segId}`)
  }

  return {
    scene: {
      sceneNo: current.sceneNo,
      version: current.version,
      segments: current.segments.map((s) => (s.segId === segId ? { ...s, text: historySeg.text } : s)),
    },
    previousText: currentSeg.text,
    restoredText: historySeg.text,
  }
}
```

- [ ] **Step 3: 实现 atomic-write.ts**

```ts
import { createHash } from 'node:crypto'
import { open, readFile, rename, unlink } from 'node:fs/promises'
import { InkloomError } from '@inkloom/shared'

export function hashContent(content: string | Uint8Array): string {
  return createHash('sha256').update(content).digest('hex')
}

export interface WriteOptions {
  /**
   * 期望的当前文件 hash（写前 CAS，spec §2.6 防线 1）。
   * - 传字符串：文件必须存在且 hash 相同
   * - 传 null：文件必须不存在
   * - 不传：不校验（仅用于确定无并发的新文件）
   */
  expectedHash?: string | null
}

export async function readIfExists(filePath: string): Promise<string | null> {
  try {
    return await readFile(filePath, 'utf8')
  } catch (e) {
    if ((e as NodeJS.ErrnoException).code === 'ENOENT') return null
    throw e
  }
}

const RENAME_RETRIES = 5
const RENAME_DELAY_MS = 40

async function renameWithRetry(from: string, to: string): Promise<void> {
  for (let i = 0; i < RENAME_RETRIES; i++) {
    try {
      await rename(from, to)
      return
    } catch (e) {
      const code = (e as NodeJS.ErrnoException).code
      // Windows 上目标文件被其他进程短暂占用会 EPERM/EBUSY/EACCES
      if (code !== 'EPERM' && code !== 'EBUSY' && code !== 'EACCES') throw e
      if (i === RENAME_RETRIES - 1) throw e
      await new Promise((r) => setTimeout(r, RENAME_DELAY_MS * (i + 1)))
    }
  }
}

/**
 * 原子写入（spec §2.6 写入顺序 步骤 0–2）。
 *
 * 顺序：CAS 校验 → 写 tmp → fsync → rename。
 * rename 是原子替换，失败时原文件完好无损。
 *
 * ★ 为什么必须有 CAS：rename 是无条件替换。没有写前 hash 比对，
 *   用户在 2s 轮询窗口内的手动编辑会被静默吞掉（ADR-26 承诺"外部编辑不丢"）。
 */
export async function atomicWrite(
  filePath: string,
  content: string,
  options: WriteOptions = {},
): Promise<{ newHash: string }> {
  if (options.expectedHash !== undefined) {
    const current = await readIfExists(filePath)
    const actual = current === null ? null : hashContent(current)
    if (actual !== options.expectedHash) {
      throw new InkloomError(
        'CAS_MISMATCH',
        `写前校验失败：${filePath} 期望 hash=${options.expectedHash ?? 'null(不存在)'}，实际=${actual ?? 'null(不存在)'}`,
      )
    }
  }

  const tmp = `${filePath}.tmp-${process.pid}-${Date.now()}`
  const handle = await open(tmp, 'w')
  try {
    await handle.writeFile(content, 'utf8')
    await handle.sync()
  } finally {
    await handle.close()
  }

  try {
    await renameWithRetry(tmp, filePath)
  } catch (e) {
    await unlink(tmp).catch(() => undefined)
    throw e
  }

  return { newHash: hashContent(content) }
}
```

- [ ] **Step 5: 实现 queue.ts**

```ts
/**
 * 单一写队列（spec §2.6 并发控制 / P0-21）。
 *
 * 所有写操作必须经过它，强制串行。理由：
 *   1. 文件系统没有事务，并发 rename 会产生不可预期的中间态
 *   2. JSONL 追加靠"串行"保证 version 单调（文件系统无唯一约束）
 *   3. SQLite 索引更新与文件写入必须成对出现
 *
 * 硬约束：即使将来恢复并行生成，写入必须串行。生成可并行，落库不可。
 */
export class WriteQueue {
  private tail: Promise<unknown> = Promise.resolve()
  private depth = 0

  run<T>(task: () => Promise<T>): Promise<T> {
    this.depth += 1
    const start = (): Promise<T> => {
      this.depth -= 1
      return task()
    }
    // then 两个回调都传同一函数：前一个失败也要继续执行，否则队列会永久卡死
    const result = this.tail.then(start, start)
    this.tail = result.catch(() => undefined)
    return result
  }

  /** 排队 + 执行中的任务数 */
  get pending(): number {
    return this.depth
  }
}

/** 进程级单例。任何写存储的代码都必须用它。 */
export const writeQueue = new WriteQueue()
```

```ts
/**
 * 索引数据库（可丢弃的派生层）。
 * 每个书根目录对应一个 index.sqlite，路径是 <bookRoot>/.inkloom/index.sqlite。
 * 测试中需要多本并存，所以提供 openIndexDb 而不是全局单例。

export async function openIndexDb(sqlitePath: string): Promise<PrismaClient> {
  const client = new PrismaClient({
    datasources: { db: { url: `file:${sqlitePath}` } },
  })
  await client.$connect()
  // spec §2.6 并发控制：WAL + busy_timeout
  await client.$executeRawUnsafe('PRAGMA journal_mode=WAL')
  await client.$executeRawUnsafe('PRAGMA busy_timeout=5000')
  return client
}
```

```ts
import { join } from 'node:path'
import { InkloomError } from '@inkloom/shared'
import { atomicWrite, readIfExists, type WriteOptions } from './atomic-write.js'

function abs(root: string, relPath: string): string {
  return join(root, relPath)
}

/** 读要素 JSON。不存在返回 null；JSON 损坏抛 INVALID_INPUT（绝不返回"半个对象"） */
export async function readJsonElement(root: string, relPath: string): Promise<unknown | null> {
  const raw = await readIfExists(abs(root, relPath))
  if (raw === null) return null
  try {
    return JSON.parse(raw) as unknown
  } catch (e) {
    throw new InkloomError('INVALID_INPUT', `${relPath} 不是合法 JSON：${(e as Error).message}`)
  }
}

/** 写要素 JSON。统一 2 空格缩进 + 尾换行，保证 Git diff 可读 */
export async function writeJsonElement(
  root: string,
  relPath: string,
  value: unknown,
  opts: WriteOptions = {},
): Promise<{ newHash: string }> {
  const content = `${JSON.stringify(value, null, 2)}\n`
  return atomicWrite(abs(root, relPath), content, opts)
}

/** 读 JSON 数组。不存在返回 []；不是数组抛 INVALID_INPUT */
export async function readJsonArray(root: string, relPath: string): Promise<unknown[]> {
  const v = await readJsonElement(root, relPath)
  if (v === null) return []
  if (!Array.isArray(v)) {
    throw new InkloomError('INVALID_INPUT', `${relPath} 期望是 JSON 数组`)
  }
  return v
}
```

- [ ] **Step 5: 实现 revisions.ts**

```ts
import { appendFile, mkdir, readdir, readFile } from 'node:fs/promises'
import { join } from 'node:path'
import type { RevisionRecord } from '@inkloom/core'
import { atomicWrite, readIfExists } from './atomic-write.js'
import { bookPaths } from './paths.js'

/** 非法路径字符替换，防止 entityId 逃出 revisions 目录 */
function sanitize(id: string): string {
  return id.replace(/[^A-Za-z0-9._-]/g, '_')
}

export function revisionFileRelPath(entityType: string, entityId: string): string {
  return `.inkloom/revisions/${sanitize(entityType)}__${sanitize(entityId)}.jsonl`
}

function absPath(root: string, entityType: string, entityId: string): string {
  return join(root, revisionFileRelPath(entityType, entityId))
}

/**
 * 追加一条 revision（spec §2.6 写入顺序 步骤 3）。
 *
 * ★ 必须早于索引更新：索引是可丢弃的派生层，历史是不可删的事实源。
 * ★ 必须在单一写队列内调用：version 单调性靠串行保证（文件系统无唯一约束）。
 */
export async function appendRevision(root: string, rec: RevisionRecord): Promise<void> {
  const p = absPath(root, rec.entityType, rec.entityId)
  await mkdir(join(bookPaths(root).revisions), { recursive: true })
  await appendFile(p, `${JSON.stringify(rec)}\n`, 'utf8')
}

/** 读取某实体的全部 revision。损坏行跳过（JSONL 逐行容错） */
export async function readRevisions(
  root: string,
  entityType: string,
  entityId: string,
): Promise<RevisionRecord[]> {
  const raw = await readIfExists(absPath(root, entityType, entityId))
  if (raw === null) return []
  const out: RevisionRecord[] = []
  for (const line of raw.split('\n')) {
    const t = line.trim()
    if (t.length === 0) continue
    try {
      out.push(JSON.parse(t) as RevisionRecord)
    } catch {
      // 跳过损坏行：宁可少一条，也不要整本历史读不出来
    }
  }
  return out
}

export async function lastRevision(
  root: string,
  entityType: string,
  entityId: string,
): Promise<RevisionRecord | null> {
  const list = await readRevisions(root, entityType, entityId)
  return list.length === 0 ? null : (list[list.length - 1] as RevisionRecord)
}

export async function countRevisionLines(
  root: string,
  entityType: string,
  entityId: string,
): Promise<number> {
  const raw = await readIfExists(absPath(root, entityType, entityId))
  if (raw === null) return 0
  return raw.split('\n').filter((l) => l.trim().length > 0).length
}

/**
 * 截断到指定行数（时间点回退用，spec §2.7 五）。
 * ★ 必须与 `git checkout <ref>` 在同一事务语义内执行，
 *   否则会出现「正文回到第 7 章、角色状态还在第 12 章」。
 */
export async function truncateRevisions(
  root: string,
  entityType: string,
  entityId: string,
  keepLines: number,
): Promise<void> {
  const list = await readRevisions(root, entityType, entityId)
  const kept = list.slice(0, Math.max(0, keepLines))
  const content = kept.length === 0 ? '' : `${kept.map((r) => JSON.stringify(r)).join('\n')}\n`
  await atomicWrite(absPath(root, entityType, entityId), content)
}

/** 列出所有 revision 文件（相对书根的 POSIX 路径），reindex 用 */
export async function readAllRevisionFiles(root: string): Promise<string[]> {
  const dir = bookPaths(root).revisions
  try {
    const names = await readdir(dir)
    return names.filter((n) => n.endsWith('.jsonl')).map((n) => `.inkloom/revisions/${n}`)
  } catch (e) {
    if ((e as NodeJS.ErrnoException).code === 'ENOENT') return []
    throw e
  }
}

/** 读单个 revision 文件的原始行（reindex 时按行解析） */
export async function readRevisionFileRaw(root: string, relPath: string): Promise<string> {
  return (await readFile(join(root, relPath), 'utf8')) ?? ''
}
```

```ts
import { randomUUID } from 'node:crypto'
import { mkdir } from 'node:fs/promises'
import { join } from 'node:path'

  rootPath: string
  name: string
  genre: string
  totalChapters?: number
  wordsPerChapter?: number
  coreIdea?: string
  premise?: string
  theme?: string
  toneContract?: string
}

  project: Project
  folderId: string
  paths: BookPaths
}

function newId(prefix: string): string {
  return `${prefix}_${randomUUID().replace(/-/g, '').slice(0, 16)}`
}

export async function readProjectId(rootPath: string): Promise<string | null> {
  return readIfExists(bookPaths(rootPath).projectIdFile)
}

/** 建书时写入的空容器，避免后续读取方到处判 undefined */
const EMPTY_CONTAINERS: ReadonlyArray<readonly [string, unknown]> = [
  ['characters/index.json', []],
  ['characters/relations.json', []],
  ['characters/signatures.json', []],
  ['world/rules.json', []],
  ['world/locations.json', []],
  ['world/routes.json', []],
  ['story/arcs.json', []],
  ['story/threads.json', []],
  ['story/techniques.json', []],
]

/**
 * 建书（P0-1 / P0-17）。
 * 铁律：一本书 = 一个文件夹。所有数据都在里面，用户可整个拷走。
 * 幂等策略：已存在 project-id 则拒绝，**绝不覆盖**（宁可报错也不毁数据）。
 */
export async function createProject(input: CreateProjectInput): Promise<OpenedProject> {
  const paths = bookPaths(input.rootPath)

  const existing = await readProjectId(input.rootPath)
  if (existing !== null) {
    throw new InkloomError('CONFLICT', `${input.rootPath} 已是一本 inkloom 书（folderId=${existing}）`)
  }

  const dirs = [
    paths.world, paths.characters, paths.story, paths.chapters, paths.styles,
    paths.assets, join(paths.assets, 'characters'), join(paths.assets, 'references'),
    paths.inkloom, paths.revisions, paths.runs, join(paths.story, 'blueprints'),
  ]
  for (const d of dirs) await mkdir(d, { recursive: true })

  const folderId = randomUUID().replace(/-/g, '')

  const project = projectSchema.parse({
    id: newId('proj'),
    folderId,
    rootPath: input.rootPath.split('\\').join('/'),
    name: input.name,
    genre: input.genre,
    ...(input.totalChapters === undefined ? {} : { totalChapters: input.totalChapters }),
    ...(input.wordsPerChapter === undefined ? {} : { wordsPerChapter: input.wordsPerChapter }),
    ...(input.coreIdea === undefined ? {} : { coreIdea: input.coreIdea }),
    ...(input.premise === undefined ? {} : { premise: input.premise }),
    ...(input.theme === undefined ? {} : { theme: input.theme }),
    ...(input.toneContract === undefined ? {} : { toneContract: input.toneContract }),
    anchorLocked: false,
    status: 'draft',
    createdAt: new Date().toISOString(),
  })

  await atomicWrite(paths.projectIdFile, folderId)
  await writeJsonElement(input.rootPath, 'novel.json', project)
  for (const [rel, value] of EMPTY_CONTAINERS) {
    await writeJsonElement(input.rootPath, rel, value)
  }
  await atomicWrite(
    join(input.rootPath, 'README.md'),
    `# ${input.name}\n\n由 inkloom 管理。正文在 \`chapters/\`，设定在 \`world/\` 与 \`characters/\`。\n` +
      `索引在 \`.inkloom/index.sqlite\`（可删，执行 \`inkloom reindex\` 可重建）。\n`,
  )

  return { project, folderId, paths }
}

/**
 * 开书（P0-17）。
 * 双重校验：project-id 存在 + 与 novel.json 的 folderId 一致。
 * 理由：书文件夹被移动/改名后，路径变了但身份不能错——防止把 A 书当成 B 书。
 */
export async function openProject(rootPath: string): Promise<OpenedProject> {
  const paths = bookPaths(rootPath)
  const folderId = await readProjectId(rootPath)
  if (folderId === null) {
    throw new InkloomError('NOT_FOUND', `${rootPath} 不是 inkloom 书（缺 .inkloom/project-id）`)
  }

  const raw = await readJsonElement(rootPath, 'novel.json')
  if (raw === null) {
    throw new InkloomError('NOT_FOUND', `${rootPath} 缺少 novel.json`)
  }

  const parsed = projectSchema.safeParse(raw)
  if (!parsed.success) {
    throw new InkloomError('INVALID_INPUT', `novel.json 校验失败：${parsed.error.issues[0]?.message ?? ''}`)
  }

  if (parsed.data.folderId !== folderId) {
    throw new InkloomError(
      'CONFLICT',
      `身份不一致：project-id=${folderId}，novel.json.folderId=${parsed.data.folderId}`,
    )
  }

  return { project: parsed.data, folderId, paths }
}
```

```ts
/**

 * 设计前提：**索引里的一切都可丢弃**。所以先清空，再从文件读。
 * 扫描范围（spec §2.6 索引重建）：
 *   .json  → Project / Character / WorldRule / Blueprint / PlotThread / ...
 *   .md    → Chapter / DraftSegment（含段标记解析）
 *   .jsonl → EntityRevision（★ 上一轮审查的阻塞点：原设计漏了它）
 *
 * 容错策略：单个文件坏 → 记 warning 并跳过，绝不中断整个重建。
 * 理由：宁可索引少一条（可再修），也不能让用户卡在"重建失败"上无法启动。
 */
export async function reindex(root: string, db: IndexDb): Promise<ReindexReport> {
  const paths = bookPaths(root)
  const warnings: string[] = []

  // 1. 清空（顺序：先子后父，避免外键冲突）
  await db.draftSegment.deleteMany()
  await db.chapter.deleteMany()
  await db.scenePlan.deleteMany()
  await db.entityRevision.deleteMany()
  await db.characterRelation.deleteMany()
  await db.characterSignature.deleteMany()
  await db.character.deleteMany()
```

```ts
import { execFile } from 'node:child_process'
import { promisify } from 'node:util'
import { InkloomError } from '@inkloom/shared'
import { WriteQueue } from '../storage/queue.js'

const exec = promisify(execFile)

/**
 * Git 子进程独立串行队列（spec §2.6 并发控制）。
 * 不能与文件写队列共用一个实例——Git 自身会拿 index.lock，
 * 与文件写混在一起会互相阻塞，导致长任务卡住整个应用。
 */
const gitQueue = new WriteQueue()

const IDENTITY_ENV = {
  GIT_AUTHOR_NAME: 'inkloom',
  GIT_AUTHOR_EMAIL: 'inkloom@localhost',
  GIT_COMMITTER_NAME: 'inkloom',
  GIT_COMMITTER_EMAIL: 'inkloom@localhost',
}

export async function isRepo(cwd: string): Promise<boolean> {
  try {
    await exec('git', ['rev-parse', '--git-dir'], { cwd })
    return true
  } catch {
    return false
  }
}

/** 幂等：已是 repo 时什么都不做 */
export async function initRepo(cwd: string): Promise<void> {
  if (await isRepo(cwd)) return
  await gitQueue.run(async () => {
    try {
      await exec('git', ['init', '-b', 'main'], { cwd, env: { ...process.env, ...IDENTITY_ENV } })
    } catch (e) {
      throw new InkloomError('GIT_FAILED', `git init 失败：${(e as Error).message}`)
    }
  })
}

/** 所有 git 调用的唯一入口，强制串行 */
export async function git(cwd: string, args: string[]): Promise<string> {
  return gitQueue.run(async () => {
    try {
      const { stdout } = await exec('git', args, {
        cwd,
        env: { ...process.env, ...IDENTITY_ENV },
        maxBuffer: 16 * 1024 * 1024,
      })
      return stdout
    } catch (e) {
      const stderr = (e as { stderr?: string }).stderr ?? (e as Error).message
      throw new InkloomError('GIT_FAILED', `git ${args.join(' ')} 失败：${stderr.trim()}`)
    }
  })
}

export interface CommitResult {
  committed: boolean
  hash: string | null
}

/**
 * 提交工作区全部改动（spec §2.5 版本用 Git）。
 * 幂等：无变更时返回 { committed: false }，不产生空 commit。
 * ★ commit message 通过 `-F -` + stdin 传入 UTF-8 字节，
 *   避免 Windows 下 PowerShell 把中文按 GBK 转码导致乱码。
 */
export async function commitAll(cwd: string, message: string): Promise<CommitResult> {
  return gitQueue.run(async () => {
    if (!(await isRepo(cwd))) {
      throw new InkloomError('GIT_FAILED', `${cwd} 不是 git 仓库`)
    }
    await exec('git', ['add', '-A'], { cwd, env: { ...process.env, ...IDENTITY_ENV } })
    const { stdout: status } = await exec('git', ['status', '--porcelain'], {
      cwd,
      env: { ...process.env, ...IDENTITY_ENV },
    })
    if (status.trim().length === 0) return { committed: false, hash: null }

    try {
      const child = exec('git', ['commit', '-F', '-'], {
        cwd,
        env: { ...process.env, ...IDENTITY_ENV },
      }) as unknown as { child: { stdin: { end(b: Buffer): void } } }
      child.child.stdin.end(Buffer.from(message, 'utf8'))
    } catch (e) {
      throw new InkloomError('GIT_FAILED', `git commit 失败：${(e as Error).message}`)
    }

    const { stdout: hash } = await exec('git', ['rev-parse', '--short', 'HEAD'], {
      cwd,
      env: { ...process.env, ...IDENTITY_ENV },
    })
    return { committed: true, hash: hash.trim() }
  })
}

export async function currentHead(cwd: string): Promise<string | null> {
  try {
    const out = await git(cwd, ['rev-parse', 'HEAD'])
    return out.trim()
  } catch {
    return null
  }
}

/** 把指定路径恢复到某个 commit（时间点回退用） */
export async function checkoutPaths(cwd: string, ref: string, paths: string[]): Promise<void> {
  if (paths.length === 0) return
  await git(cwd, ['checkout', ref, '--', ...paths])
}

export async function hasChanges(cwd: string, paths: string[]): Promise<boolean> {
  const out = await git(cwd, ['status', '--porcelain', '--', ...paths])
  return out.trim().length > 0
}
```

> ⚠️ **Step 3 的 `commitAll` 里 stdin 写法需要按实际 `execFile` 行为调整**。
> 更稳的写法是用 `spawn` 直接拿子进程：

> function commitWithStdin(cwd: string, message: string): Promise<void> {

>       cwd, env: { ...process.env, ...IDENTITY_ENV }, stdio: ['pipe', 'pipe', 'pipe'],

>     child.stderr.on('data', (d: Buffer) => { stderr += d.toString('utf8') })
>     child.on('error', reject)
>     child.on('close', (code) => {

```ts
import { dirname, join } from 'node:path'
import { parseSceneFile, serializeSceneFile, type SceneFile } from '@inkloom/core'
import { atomicWrite, readIfExists } from './atomic-write.js'

const pad3 = (n: number): string => String(n).padStart(3, '0')

/** 候选稿路径（§2.7 一）。章号补 3 位，场景号与版本号不补 */
export function sceneRelPath(chapterNo: number, sceneNo: number, version: number): string {
  return `chapters/ch-${pad3(chapterNo)}/scenes/s${sceneNo}.v${version}.md`
}

/**
 * 写一个场景版本。
 * ★ 永远写新文件，**绝不覆盖旧版本**——回退依赖旧版本存在。
 */
export async function writeSceneFile(
  root: string,
  scene: SceneFile,
  chapterNo: number,
): Promise<{ relPath: string; newHash: string }> {
  const relPath = sceneRelPath(chapterNo, scene.sceneNo, scene.version)
  const abs = join(root, relPath)
  await mkdir(dirname(abs), { recursive: true })
  const { newHash } = await atomicWrite(abs, serializeSceneFile(scene))
  return { relPath, newHash }
}

export async function readSceneFile(
  root: string,
  chapterNo: number,
  sceneNo: number,
  version: number,
): Promise<SceneFile | null> {
  const raw = await readIfExists(join(root, sceneRelPath(chapterNo, sceneNo, version)))
  return raw === null ? null : parseSceneFile(raw)
}

async function listSceneFiles(root: string, chapterNo: number): Promise<string[]> {
  const dir = join(root, 'chapters', `ch-${pad3(chapterNo)}`, 'scenes')
  try {
    return await readdir(dir)
  } catch (e) {
    if ((e as NodeJS.ErrnoException).code === 'ENOENT') return []
    throw e
  }
}

/** 某场景的全部版本号，升序 */
export async function listSceneVersions(
  root: string,
  chapterNo: number,
  sceneNo: number,
): Promise<number[]> {
  const files = await listSceneFiles(root, chapterNo)
  const re = new RegExp(`^s${sceneNo}\\.v(\\d+)\\.md$`)
  const versions: number[] = []
  for (const f of files) {
    const m = re.exec(f)
    if (m) versions.push(Number(m[1]))
  }
  return versions.sort((a, b) => a - b)
}

export async function latestSceneVersion(
  root: string,
  chapterNo: number,
  sceneNo: number,
): Promise<number | null> {
  const vs = await listSceneVersions(root, chapterNo, sceneNo)
  return vs.length === 0 ? null : (vs[vs.length - 1] as number)
}
```

```ts
import { randomBytes } from 'node:crypto'
import { join } from 'node:path'
import { parseChapterFile, serializeChapterFile, splitParagraphs, type SceneFile } from '@inkloom/core'
import { atomicWrite, readIfExists } from './atomic-write.js'
import { latestSceneVersion } from './scenes.js'

const pad3 = (n: number): string => String(n).padStart(3, '0')

export function chapterRelPath(chapterNo: number): string {
  return `chapters/ch-${pad3(chapterNo)}.md`
}

export interface MergeInput {
  chapterNo: number
  title: string
  scenes: { sceneNo: number; text: string }[]
}

/**
 * 定稿合并（§2.7 二）。
 * 输入是"已接受的场景正文"（不含段标记），输出是干净的定稿文件。
 * 场景边界用 <!-- scene:N --> 保留——它是撤销定稿时反解的唯一依据。
 */
export async function mergeChapter(
  root: string,
  input: MergeInput,
): Promise<{ relPath: string; newHash: string }> {
  const relPath = chapterRelPath(input.chapterNo)
  const content = serializeChapterFile({
    title: input.title,
    scenes: input.scenes
      .filter((s) => s.text.trim().length > 0)
      .map((s) => ({ sceneNo: s.sceneNo, text: s.text })),
  })
  const { newHash } = await atomicWrite(join(root, relPath), content)
  return { relPath, newHash }
}

const ALPHABET = '0123456789abcdefghijklmnopqrstuvwxyz'

/** 反解时重分配段 ID（§2.7 三）。用 crypto 随机源，保证与既有 ID 冲突概率可忽略 */
function freshSegId(): string {
  const bytes = randomBytes(4)
  let id = ''
  for (let i = 0; i < 4; i++) {
    id += ALPHABET[(bytes[i] as number) % ALPHABET.length]
  }
  return id
}

/**
 * 撤销定稿的反解（§2.7 三）。
 *
 * 语义：读 ch-NNN.md → 按场景边界切分 → 每场景重建一个 SceneFile。
 * ★ 段 ID 是新分配的：定稿文件本来就不含段标记，旧 ID 已随定稿丢弃。
 *   这是**有意的代价**——正文一字节不丢，但旧的段级回退记录会失效。
 * ★ version = 该场景已有最新版本 + 1，保证不覆盖历史候选稿。
 */
export async function splitChapter(
  root: string,
  chapterNo: number,
): Promise<{ chapterNo: number; title: string; scenes: SceneFile[] } | null> {
  const raw = await readIfExists(join(root, chapterRelPath(chapterNo)))
  if (raw === null) return null

  const parsed = parseChapterFile(raw)
  const scenes: SceneFile[] = []

  for (const s of parsed.scenes) {
    if (s.text.trim().length === 0) continue
    const latest = await latestSceneVersion(root, chapterNo, s.sceneNo)
    scenes.push({
      sceneNo: s.sceneNo,
      version: (latest ?? 0) + 1,
      segments: splitParagraphs(s.text).map((text) => ({ segId: freshSegId(), text })),
    })
  }

  return { chapterNo, title: parsed.title, scenes }
}
```

```ts
import { join } from 'node:path'
import { InkloomError } from '@inkloom/shared'
import { checkoutPaths, commitAll, currentHead, initRepo } from '../git/runner.js'
import { readIfExists } from './atomic-write.js'
import { bookPaths } from './paths.js'
import { countRevisionLines, readAllRevisionFiles, truncateRevisions } from './revisions.js'

export interface Checkpoint {
  id: string
  label: string
  createdAt: string
  gitRef: string | null
  /** key = revision 文件相对路径，value = 当时的非空行数 */
  revisionsOffsets: Record<string, number>
}

export function checkpointRelPath(): string {
  return '.inkloom/checkpoints.jsonl'
}

/** checkpoint / 回退 / reindex 需要恢复的路径集合（spec §2.7 五） */
const TRACKED_DIRS = ['chapters', 'characters', 'world', 'story', 'styles', 'novel.json']

export async function readCheckpoints(root: string): Promise<Checkpoint[]> {
  const raw = await readIfExists(join(root, checkpointRelPath()))
  if (raw === null) return []
  const out: Checkpoint[] = []
  for (const line of raw.split('\n')) {
    const t = line.trim()
    if (t.length === 0) continue
    try {
      out.push(JSON.parse(t) as Checkpoint)
    } catch {

    }
  }
  return out
}

/**
 * 建检查点（§2.7 五）。
 * 记录两样东西：Git HEAD + 每个 revision 文件的行数。
 * ★ 两者缺一不可——只记 Git 会让要素状态"穿越"到未来章节。
 */
export async function createCheckpoint(root: string, label: string): Promise<Checkpoint> {
  await initRepo(root)
  // 先把当前状态提交，保证 gitRef 指向"这一刻"而不是上一次提交
  await commitAll(root, `chore(checkpoint): ${label}`)
  const gitRef = await currentHead(root)

  const revisionsOffsets: Record<string, number> = {}
  for (const rel of await readAllRevisionFiles(root)) {
    const file = rel.replace('.inkloom/revisions/', '').replace('.jsonl', '')
    const sep = file.indexOf('__')
    if (sep < 0) continue
    const entityType = file.slice(0, sep)
    const entityId = file.slice(sep + 2)
    revisionsOffsets[rel] = await countRevisionLines(root, entityType, entityId)
  }

  const ck: Checkpoint = {
    id: `ck-${randomUUID().slice(0, 8)}`,
    label,
    createdAt: new Date().toISOString(),
    gitRef,
    revisionsOffsets,
  }
  await mkdir(bookPaths(root).inkloom, { recursive: true })
  await appendFile(join(root, checkpointRelPath()), `${JSON.stringify(ck)}\n`, 'utf8')
  return ck
}

export interface RollbackToCheckpointResult {
  restoredPaths: string[]
  truncatedRevisionFiles: string[]
  warnings: string[]
}

/**
 * 时间点回退（§2.7 五 / P0-10 第四种）。
 *
 * 步骤：git checkout <ref> -- <tracked> → 逐个截断 JSONL → 追加 rollback checkpoint。
 * ★ 顺序不可换：先恢复文件再截断历史。若中途崩溃，重跑本函数是幂等的
 *   （checkout 与 truncate 都幂等）。
 */
export async function rollbackToCheckpoint(
  root: string,
  checkpointId: string,
): Promise<RollbackToCheckpointResult> {
  const all = await readCheckpoints(root)
  const ck = all.find((c) => c.id === checkpointId)
  if (ck === undefined) {
    throw new InkloomError('NOT_FOUND', `checkpoint ${checkpointId} 不存在`)
  }

  const restoredPaths: string[] = []
  const truncatedRevisionFiles: string[] = []
  const warnings: string[] = []

  if (ck.gitRef === null) {
    warnings.push('checkpoint 没有 gitRef（创建时尚未提交），仅回退要素历史')
  } else {
    await checkoutPaths(root, ck.gitRef, TRACKED_DIRS)
    restoredPaths.push(...TRACKED_DIRS)
  }

  for (const [rel, keepLines] of Object.entries(ck.revisionsOffsets)) {
    const file = rel.replace('.inkloom/revisions/', '').replace('.jsonl', '')
    const sep = file.indexOf('__')
    if (sep < 0) {
      warnings.push(`无法解析 revision 文件名：${rel}`)
      continue
    }
    const entityType = file.slice(0, sep)
    const entityId = file.slice(sep + 2)
    await truncateRevisions(root, entityType, entityId, keepLines)
    truncatedRevisionFiles.push(rel)
  }

  // 回退本身也留痕（P0-10 要求）
  await createCheckpoint(root, `回退到 ${ck.label} (${ck.id})`)

  return { restoredPaths, truncatedRevisionFiles, warnings }
}
```

```ts
import { randomUUID } from 'node:crypto'
import { join } from 'node:path'
import { nextRevision, type ChangeSource, type EntityType, type RevisionRecord } from '@inkloom/core'
import { InkloomError } from '@inkloom/shared'
import { commitAll } from '../git/runner.js'
import { writeJsonElement, readJsonElement } from '../storage/elements.js'
import { hashContent, readIfExists } from '../storage/atomic-write.js'
import { writeQueue } from '../storage/queue.js'
import { appendRevision, lastRevision, readRevisions } from '../storage/revisions.js'
import { getContext } from './context.js'

export interface UpsertElementInput {
  entityType: EntityType
  entityId: string
  relPath: string
  payload: unknown
  changeSource: ChangeSource
  changeReason?: string
}

export interface UpsertResult {
  version: number
  newHash: string
}

/**
 * 写一个要素（spec §2.6 写入顺序的完整落地）。
 *
 * 顺序（不可调换）：
 *   0. 写前 CAS（读当前文件 hash）
 *   1–2. tmp → fsync → rename
 *   3. 追加 JSONL revision   ← 必须早于索引
 *   4. 更新索引（事务）
 *   5. git commit
 *
 * 全程在单一写队列内，保证 version 单调与文件/历史/索引三者一致。
 */
export async function upsertElement(input: UpsertElementInput): Promise<UpsertResult> {
  const { root } = getContext()

  return writeQueue.run(async () => {
    const prev = await lastRevision(root, input.entityType, input.entityId)
    // ★ 用 join 拼接，不要手写 "${root}/${rel}"——Windows 盘符会混斜杠
    const existing = await readIfExists(join(root, input.relPath))
    const expectedHash = existing === null ? null : hashContent(existing)

    const revision: RevisionRecord = nextRevision({
      id: `rev_${randomUUID().replace(/-/g, '').slice(0, 16)}`,
      entityType: input.entityType,
      entityId: input.entityId,
      prev,
      payload: input.payload,
      changeSource: input.changeSource,
      ...(input.changeReason === undefined ? {} : { changeReason: input.changeReason }),
      now: new Date().toISOString(),
    })

    // 1–2. 文件
    const { newHash } = await writeJsonElement(root, input.relPath, input.payload, { expectedHash })

    // 3. 历史（早于索引）
    await appendRevision(root, revision)

    // 5. git（索引由调用方或 reindex 负责；P0 不在此处同步索引，避免半成品状态）
    await commitAll(root, `feat(${input.entityType}): ${input.entityId} v${revision.version}`)

    return { version: revision.version, newHash }
  })
}

export interface RollbackElementInput {
  entityType: EntityType
  entityId: string
  relPath: string
  toVersion: number
}

/**
 * 要素回退（P0-10 第三种）。
 * ★ 回退 = 产生新版本，不改历史。旧版本永远在 JSONL 里。
 */
export async function rollbackElement(input: RollbackElementInput): Promise<UpsertResult> {
  const { root } = getContext()
  const revs = await readRevisions(root, input.entityType, input.entityId)
  const target = revs.find((r) => r.version === input.toVersion)
  if (target === undefined) {
    throw new InkloomError(
      'NOT_FOUND',
      `${input.entityType}/${input.entityId} 不存在版本 ${input.toVersion}`,
    )
  }
  const payload: unknown = JSON.parse(target.payload)
  return upsertElement({
    entityType: input.entityType,
    entityId: input.entityId,
    relPath: input.relPath,
    payload,
    changeSource: 'rollback',
    changeReason: `回退到 v${input.toVersion}`,
  })
}

export async function listElementRevisions(
  entityType: EntityType,
  entityId: string,
): Promise<RevisionRecord[]> {
  const { root } = getContext()
  return readRevisions(root, entityType, entityId)
}

/** 读要素当前值（文件为准） */
export async function readElement(relPath: string): Promise<unknown | null> {
  const { root } = getContext()
  return readJsonElement(root, relPath)
}
```

> **说明：本任务暂不同步 SQLite 索引。**
> 理由：P0 的索引是"可丢弃派生层"，验收标准是 `reindex` 后数据一致。
> 每次写都同步索引会引入"文件已写、索引失败"的半成品态，需要补偿逻辑。
> **Task 17 会加 `syncIndex()` 并在写成功后调用**——先保证正确，再加性能。

```ts
import {
  rollbackSegment as rollbackSegmentPure, type SceneFile,
} from '@inkloom/core'
import { InkloomError } from '@inkloom/shared'
import { commitAll } from '../git/runner.js'
import { mergeChapter, splitChapter } from '../storage/chapters.js'
import { writeQueue } from '../storage/queue.js'
import {
  latestSceneVersion, readSceneFile, writeSceneFile,
} from '../storage/scenes.js'
import { getContext } from './context.js'

const SEG_ID_RE = /^[0-9a-z]{4}$/

export interface SaveSceneInput {
  chapterNo: number
  sceneNo: number
  segments: { segId: string; text: string }[]
}

/** 保存一个场景的新版本。★ 永远新增版本，不覆盖旧版本 */
export async function saveScene(input: SaveSceneInput): Promise<{ version: number; relPath: string }> {
  const { root } = getContext()
  for (const s of input.segments) {
    if (!SEG_ID_RE.test(s.segId)) {
      throw new InkloomError('INVALID_INPUT', `段 ID 必须是 4 位 base36：${s.segId}`)
    }
  }
  return writeQueue.run(async () => {
    const latest = await latestSceneVersion(root, input.chapterNo, input.sceneNo)
    const scene: SceneFile = {
      sceneNo: input.sceneNo,
      version: (latest ?? 0) + 1,
      segments: input.segments,
    }
    const { relPath } = await writeSceneFile(root, scene, input.chapterNo)
    await commitAll(root, `feat(scene): 第 ${input.chapterNo} 章场景 ${input.sceneNo} v${scene.version}`)
    return { version: scene.version, relPath }
  })
}

export interface RollbackSegmentInput {
  chapterNo: number
  sceneNo: number
  segId: string
  toVersion: number
}

/**
 * 单段回退（P0-10 第一种）。
 * 语义：从历史版本取该段内容，替换当前最新版本的同名段，写成**新版本**。
 */
export async function rollbackSegmentToVersion(
  input: RollbackSegmentInput,
): Promise<{ newVersion: number; previousText: string; restoredText: string }> {
  const { root } = getContext()
  return writeQueue.run(async () => {
    const latestVersion = await latestSceneVersion(root, input.chapterNo, input.sceneNo)
    if (latestVersion === null) {
      throw new InkloomError('NOT_FOUND', `第 ${input.chapterNo} 章场景 ${input.sceneNo} 没有候选稿`)
    }
    const current = await readSceneFile(root, input.chapterNo, input.sceneNo, latestVersion)
    const history = await readSceneFile(root, input.chapterNo, input.sceneNo, input.toVersion)
    if (current === null || history === null) {
      throw new InkloomError('NOT_FOUND', `场景版本不存在（当前 v${latestVersion}，目标 v${input.toVersion}）`)
    }

    const result = rollbackSegmentPure(current, history, input.segId)
    const next: SceneFile = {
      sceneNo: current.sceneNo,
      version: latestVersion + 1,
      segments: result.scene.segments,
    }
    await writeSceneFile(root, next, input.chapterNo)
    await commitAll(
      root,
      `fix(scene): 第 ${input.chapterNo} 章场景 ${input.sceneNo} 单段回退段 ${input.segId} 至 v${input.toVersion}`,
    )
    return {
      newVersion: next.version,
      previousText: result.previousText,
      restoredText: result.restoredText,
    }
  })
}

/** 定稿：把所有场景的最新版本合并为 ch-NNN.md */
export async function finalizeChapter(
  chapterNo: number,
  title: string,
): Promise<{ relPath: string }> {
  const { root } = getContext()
  return writeQueue.run(async () => {
    const { readdir } = await import('node:fs/promises')
    const dir = `${root}/chapters/ch-${String(chapterNo).padStart(3, '0')}/scenes`
    let files: string[]
    try {
      files = await readdir(dir)
    } catch {
      throw new InkloomError('NOT_FOUND', `第 ${chapterNo} 章没有候选稿`)
    }
    const sceneNos = [...new Set(
      files.map((f) => /^s(\d+)\.v\d+\.md$/.exec(f)?.[1]).filter((x): x is string => x !== undefined)
        .map(Number),
    )].sort((a, b) => a - b)

    const scenes: { sceneNo: number; text: string }[] = []
    for (const sceneNo of sceneNos) {
      const v = await latestSceneVersion(root, chapterNo, sceneNo)
      if (v === null) continue
      const scene = await readSceneFile(root, chapterNo, sceneNo, v)
      if (scene === null) continue
      scenes.push({ sceneNo, text: scene.segments.map((s) => s.text).join('\n\n') })
    }

    const { relPath } = await mergeChapter(root, { chapterNo, title, scenes })
    await commitAll(root, `feat(chapter): 第 ${chapterNo} 章定稿`)
    return { relPath }
  })
}

/** 撤销定稿：反解 ch-NNN.md 回候选（段 ID 重分配，正文不丢） */
export async function unfinalizeChapter(chapterNo: number): Promise<{ scenes: number }> {
  const { root } = getContext()
  return writeQueue.run(async () => {
    const out = await splitChapter(root, chapterNo)
    if (out === null) {
      throw new InkloomError('NOT_FOUND', `第 ${chapterNo} 章尚未定稿`)
    }
    for (const scene of out.scenes) {
      await writeSceneFile(root, scene, chapterNo)
    }
    await commitAll(root, `chore(chapter): 撤销第 ${chapterNo} 章定稿`)
    return { scenes: out.scenes.length }
  })
}
```

```ts
import { readdir } from 'node:fs/promises'
import { join } from 'node:path'
import { readJsonElement } from '../storage/elements.js'
import { bookPaths } from '../storage/paths.js'
import { readAllRevisionFiles } from '../storage/revisions.js'
import { readIfExists } from '../storage/atomic-write.js'

export type ExportFormat = 'json' | 'md' | 'txt'

export interface ExportResult {
  content: string
  filename: string
  mime: string
}

const ELEMENT_FILES = [
  'novel.json',
  'characters/index.json', 'characters/relations.json', 'characters/signatures.json',
  'world/rules.json', 'world/locations.json', 'world/routes.json',
  'story/arcs.json', 'story/threads.json', 'story/techniques.json',
  'styles/default.json',
]

async function collectJson(root: string): Promise<string> {
  const novel = await readJsonElement(root, 'novel.json')
  const elements: Record<string, unknown> = {}
  for (const rel of ELEMENT_FILES) {
    if (rel === 'novel.json') continue
    const v = await readJsonElement(root, rel)
    if (v !== null) elements[rel] = v
  }

  // 蓝图单独一个目录
  const blueprints: Record<string, unknown> = {}
  try {
    for (const name of await readdir(join(bookPaths(root).story, 'blueprints'))) {
      if (!name.endsWith('.json')) continue
      const v = await readJsonElement(root, `story/blueprints/${name}`)
      if (v !== null) blueprints[name] = v
    }
  } catch {
    // 目录不存在视为空
  }

  const revisions: Record<string, unknown[]> = {}
  for (const rel of await readAllRevisionFiles(root)) {
    const raw = await readIfExists(join(root, rel))
    if (raw === null) continue
    revisions[rel] = raw
      .split('\n')
      .map((l) => l.trim())
      .filter((l) => l.length > 0)
      .flatMap((l) => {
        try {
          return [JSON.parse(l) as unknown]
        } catch {
          return []
        }
      })
  }

  const chapters: Record<string, string> = {}
  try {
    for (const name of await readdir(bookPaths(root).chapters)) {
      if (!/^ch-\d+\.md$/.test(name)) continue
      const raw = await readIfExists(join(bookPaths(root).chapters, name))
      if (raw !== null) chapters[name] = raw
    }
  } catch {
    // 空书
  }

  return `${JSON.stringify({ project: novel, elements, blueprints, chapters, revisions }, null, 2)}\n`
}

async function collectMarkdown(root: string): Promise<string> {
  const novel = await readJsonElement(root, 'novel.json')
  const name = (novel as { name?: string } | null)?.name ?? 'untitled'
  const parts: string[] = [`# ${name}\n`]
  let names: string[] = []
  try {
    names = (await readdir(bookPaths(root).chapters)).filter((n) => /^ch-\d+\.md$/.test(n))
  } catch {
    return parts.join('\n')
  }
  for (const n of names.sort()) {
    const raw = await readIfExists(join(bookPaths(root).chapters, n))
    if (raw !== null) parts.push(raw.trim(), '\n')
  }
  return parts.join('\n')
}

const HTML_COMMENT_RE = /<!--[\s\S]*?-->/g
const MD_HEADING_RE = /^#{1,6}\s+/gm

function toPlainText(markdown: string): string {
  return markdown.replace(HTML_COMMENT_RE, '').replace(MD_HEADING_RE, '').replace(/
{3,}/g, '

').trim() + '
'
}

/** 导出（P0-12）：json 整书 / md 正文 / txt 纯文本 */
export async function exportBook(format: ExportFormat, root: string): Promise<ExportResult> {
  const novel = await readJsonElement(root, 'novel.json')
  const name = (novel as { name?: string } | null)?.name ?? 'untitled'

  if (format === 'json') {
    return { content: await collectJson(root), filename: `${name}.json`, mime: 'application/json' }
  }
  const md = await collectMarkdown(root)
  if (format === 'md') {
    return { content: md, filename: `${name}.md`, mime: 'text/markdown' }
  }
  return { content: toPlainText(md), filename: `${name}.txt`, mime: 'text/plain' }
}
```

```ts
/** 极简参数解析：--key value 形式 */
export function parseFlags(args: string[]): { positional: string[]; flags: Record<string, string> } {
  const positional: string[] = []
  const flags: Record<string, string> = {}
  for (let i = 0; i < args.length; i++) {
    const a = args[i] as string
    if (a.startsWith('--')) {
      const key = a.slice(2)
      const next = args[i + 1]
      if (next !== undefined && !next.startsWith('--')) {
        flags[key] = next
        i++
      } else {
        flags[key] = 'true'
      }
    } else {
      positional.push(a)
    }
  }
  return { positional, flags }
}

export function requireFlag(flags: Record<string, string>, key: string): string {
  const v = flags[key]
  if (v === undefined) throw new Error(`缺少 --${key}`)
  return v
}
```

```ts
import type { EntityType } from '@inkloom/core'
import type { IndexDb } from './client.js'

export interface SyncResult {
  ok: boolean
  skipped?: boolean
  error?: string
}

function rec(v: unknown): Record<string, unknown> {
  return typeof v === 'object' && v !== null ? (v as Record<string, unknown>) : {}
}

const str = (v: unknown): string | null => (typeof v === 'string' ? v : null)
const num = (v: unknown): number | null => (typeof v === 'number' ? v : null)

/**
 * 把一条要素写入索引（spec §2.6 步骤 4）。
 *
 * 设计原则：**失败绝不阻塞写入**。索引是可丢弃的派生层，
 * 写入失败只需标记 dirty，待下次 reindex 修复。
 * 反过来如果因为索引失败而回滚文件写入，就把“可丢弃”变成了“关键路径”——那是错的。
 */
export async function syncElement(
  db: IndexDb,
  projectId: string,
  entityType: EntityType,
  payload: unknown,
): Promise<SyncResult> {
  const p = rec(payload)
  const id = str(p['id'])
  if (id === null) return { ok: false, error: 'payload 缺少 id' }

  try {
    switch (entityType) {
      case 'character':
        await db.character.upsert({
          where: { id },
          create: {
            id, projectId, name: str(p['name']) ?? '', role: str(p['role']) ?? 'minor',
            personality: str(p['personality']), background: str(p['background']),
            curPhysical: str(p['curPhysical']), curTierId: str(p['curTierId']),
            stateChapter: num(p['stateChapter']), stateStale: p['stateStale'] === true,
          },
          update: {
            name: str(p['name']) ?? '', role: str(p['role']) ?? 'minor',
            personality: str(p['personality']), background: str(p['background']),
            curPhysical: str(p['curPhysical']), curTierId: str(p['curTierId']),
            stateChapter: num(p['stateChapter']), stateStale: p['stateStale'] === true,
          },
        })
        return { ok: true }

      case 'blueprint':
        await db.blueprint.upsert({
          where: { projectId_chapterNo: { projectId, chapterNo: num(p['chapterNo']) ?? 0 } },
          create: {
            id, projectId, chapterNo: num(p['chapterNo']) ?? 0,
            title: str(p['title']), goal: str(p['goal']) ?? '', conflict: str(p['conflict']) ?? '',
            hook: str(p['hook']) ?? '', castIds: JSON.stringify(p['castIds'] ?? []),
            beatType: str(p['beatType']) ?? 'rising',
            tensionLevel: num(p['tensionLevel']) ?? 3,
          },
          update: {
            title: str(p['title']), goal: str(p['goal']) ?? '',
            conflict: str(p['conflict']) ?? '', hook: str(p['hook']) ?? '',
            castIds: JSON.stringify(p['castIds'] ?? []),
            beatType: str(p['beatType']) ?? 'rising',
            tensionLevel: num(p['tensionLevel']) ?? 3,
          },
        })
        return { ok: true }

      case 'world_rule':
        await db.worldRule.upsert({
          where: { id },
          create: {
            id, projectId, category: str(p['category']) ?? 'power',
            name: str(p['name']) ?? '', content: str(p['content']) ?? '',
            priority: str(p['priority']) ?? 'soft',
          },
          update: {
            category: str(p['category']) ?? 'power', name: str(p['name']) ?? '',
            content: str(p['content']) ?? '', priority: str(p['priority']) ?? 'soft',
          },
        })
        return { ok: true }

      case 'plot_thread':
        await db.plotThread.upsert({
          where: { id },
          create: {
            id, projectId, kind: str(p['kind']) ?? 'setup', title: str(p['title']) ?? '',
            plantedChapter: num(p['plantedChapter']),
            advancedChapters: JSON.stringify(p['advancedChapters'] ?? []),
            resolvedChapter: num(p['resolvedChapter']),
            status: str(p['status']) ?? 'active',

          update: {
            kind: str(p['kind']) ?? 'setup', title: str(p['title']) ?? '',
            plantedChapter: num(p['plantedChapter']),
            advancedChapters: JSON.stringify(p['advancedChapters'] ?? []),
            resolvedChapter: num(p['resolvedChapter']),
            status: str(p['status']) ?? 'active',

      default:
        // 其余类型 P0 不做实时同步（仍可 reindex 重建）
        return { ok: true, skipped: true }
    }
  } catch (e) {
    return { ok: false, error: (e as Error).message }
  }
}
```

```ts
import { InkloomError } from '@inkloom/shared'
import type { EntityType } from '@inkloom/core'
import type { IndexDb } from '../index-db/client.js'
import { getContext } from './context.js'
import { listElementRevisions, upsertElement, type UpsertResult } from './element-service.js'

/**
 * P0-22 章节号不可变。
 *
 * 允许：追加（chapterNo > max）、更新已存在的章。
 * 拒绝：中间插入（chapterNo < max 且该章不存在）。
 *
 * 理由：章号是跨表引用键（蓝图/正文/摘要/伏笔都指向它）。
 * 允许中间插入就必须对后续所有章重编号，这是不可接受的隐式副作用。
 */
export async function assertChapterAppendOnly(
  db: IndexDb,
  projectId: string,
  chapterNo: number,
): Promise<void> {
  const maxRow = await db.blueprint.findFirst({
    where: { projectId },
    orderBy: { chapterNo: 'desc' },
    select: { chapterNo: true },
  })
  const max = maxRow?.chapterNo ?? 0
  if (chapterNo > max) return   // 追加

  const exists = await db.blueprint.findUnique({
    where: { projectId_chapterNo: { projectId, chapterNo } },
    select: { id: true },
  })
  if (exists !== null) return   // 更新已有章

  throw new InkloomError(
    'CONFLICT',
    `第 ${chapterNo} 章不存在但小于已有最大章号 ${max}，不支持中间插入（P0-22 只允许末尾追加）`,
  )
}

/**
 * 软删除（P0-11）。
 * 语义：写一个新版本，在 payload 上加 deletedAt，**原数据完整保留**。
 * 这样“删除”本身也可回退（回退到删除前的版本即可）。
 */
export async function softDeleteElement(input: {
  entityType: EntityType
  entityId: string
  relPath: string
}): Promise<UpsertResult> {
  const revs = await listElementRevisions(input.entityType, input.entityId)
  const latest = revs[revs.length - 1]
  if (latest === undefined) {
    throw new InkloomError('NOT_FOUND', `${input.entityType}/${input.entityId} 不存在`)
  }
  const payload = { ...(JSON.parse(latest.payload) as Record<string, unknown>) }
  payload['deletedAt'] = new Date().toISOString()
  return upsertElement({ ...input, payload, changeSource: 'human', changeReason: '软删除' })
}

/** 恢复软删除：写一个新版本，去掉 deletedAt */
export async function restoreElement(input: {
  entityType: EntityType
  entityId: string
  relPath: string
}): Promise<UpsertResult> {
  const revs = await listElementRevisions(input.entityType, input.entityId)
  const latest = revs[revs.length - 1]
  if (latest === undefined) {
    throw new InkloomError('NOT_FOUND', `${input.entityType}/${input.entityId} 不存在`)
  }
  const payload = { ...(JSON.parse(latest.payload) as Record<string, unknown>) }
  delete payload['deletedAt']
  return upsertElement({ ...input, payload, changeSource: 'human', changeReason: '恢复删除' })
}
```
