# P2-a 局部重写实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用户指定场景里的一段，模型按指令重写这一段；产物作为新版本候选，其余段逐字节不变，段 ID 不变。

**Architecture:** 三层落地，各管一件事。`packages/prompt` 负责「怎么问模型」（纯字符串拼装）；`packages/core` 负责「模型答得算不算数」（纯函数校验，不抛错、只给判定）；`apps/api` 的 rewrite-service 负责「问、校验、落盘」，落盘直接复用已有的 `editSceneSeg`，不新开写盘路径。

**Tech Stack:** TypeScript / Zod / Hono / Vitest / DeepSeek chat adapter / React 19 + TanStack Query

**Spec:** `docs/superpowers/specs/2026-10-25-inkloom-design.md` §4.19（本轮新增）

## Global Constraints

- `packages/core` 与 `packages/prompt` **零 IO**：不读文件、不发请求、不碰数据库（`pnpm check-deps` 强制）。
- 文件是唯一真相：校验不过就**不写任何文件**；不允许先写后删。
- 落盘一律走 `editSceneSeg`（旧版本整版 rejected、段 ID 不变、Git 提交），不复制它的逻辑。
- 错误码语义：`NOT_FOUND`=404、`CONFLICT`=409、`INVALID_INPUT`=400。
- 长度边界：输出字数 `< 原文 40%` 或 `> 原文 300%` 判为跑题（字数用 `countWords`，忽略标点空白）。
- 测试全程假 LLM（`FetchLike` 注入），不产生真实 API 费用。
- 提交信息用 `-F -` 送 stdin（Windows 上 `-m` 会把中文按 GBK 转码）。

```ts
import { countWords } from './words.js'

export type RewriteVerdict =
  | { ok: true; text: string }
  | { ok: false; reason: 'empty' | 'too_short' | 'too_long' | 'has_marker' }

const FENCE_RE = /^```[a-z]*\n?|\n?```$/g
const QUOTE_PAIRS: [string, string][] = [
  ['“', '”'],
  ['「', '」'],
  ['"', '"'],
  ["'", "'"],
]
const MARKER_RE = /<!--[\s\S]*?-->/g

/**
 * 清洗模型返回的单段文本，并判断它是否还值得落盘。
 *
 * 返回判定而不是抛错：core 是纯函数层，不依赖错误类型；
 * 由 api 层把 reason 翻译成 INVALID_INPUT 与中文提示。
 */
export function sanitizeRewrittenSegment(raw: string, original: string): RewriteVerdict {
  let text = raw.replace(FENCE_RE, '').trim()

  for (const [open, close] of QUOTE_PAIRS) {
    if (text.length >= 2 && text.startsWith(open) && text.endsWith(close)) {
      text = text.slice(open.length, text.length - close.length).trim()
    }
  }

  // ★ 先判标记：模型把 <!-- seg --> 写进来时必须拒绝，而不是悄悄删掉——
  //   它意味着模型在"补全整段场景文本"而不是"改写这一段"。
  if (MARKER_RE.test(text)) return { ok: false, reason: 'has_marker' }

  if (text.length === 0 || countWords(text) === 0) return { ok: false, reason: 'empty' }

  const before = countWords(original)
  if (before > 0) {
    const after = countWords(text)
    if (after < before * 0.4) return { ok: false, reason: 'too_short' }
    if (after > before * 3) return { ok: false, reason: 'too_long' }
  }
  return { ok: true, text }
}
```

```ts
import type { PromptMessage } from '../assemble.js'

export interface RewriteInput {
  chapterNo: number
  sceneNo: number
  sceneGoal: string | null
  conflict: string | null
  hook: string | null
  prevText: string | null
  nextText: string | null
  original: string
  guidance: string | null
}

const SYSTEM = `你是中文小说编辑，任务是改写**一个段落**。

硬性要求：
1. 只输出这一段的新文本。不要输出场景标题、段标记（<!-- seg:xxxx -->）、
   代码围栏、引号包裹，也不要输出任何解释或前后缀。
2. 保持与前后段相同的时态、人称与文风；不要引入前文没有的人物或设定。
3. 改写是"换一种写法"，不是删减情节：原文里的动作与后果必须还在。
4. 篇幅与原文相当（原文字数的 0.5–1.5 倍）。`

export function buildRewriteMessages(input: RewriteInput): PromptMessage[] {
  const lines: string[] = [
    `第 ${input.chapterNo} 章 · 场景 ${input.sceneNo}`,
  ]
  if (input.sceneGoal !== null) lines.push(`本章目的：${input.sceneGoal}`)
  if (input.conflict !== null) lines.push(`本章冲突：${input.conflict}`)
  if (input.hook !== null) lines.push(`本章钩子：${input.hook}`)
  if (input.prevText !== null) lines.push(`\n上一段：\n${input.prevText}`)
  if (input.nextText !== null) lines.push(`\n下一段：\n${input.nextText}`)
  lines.push(`\n<<<原文\n${input.original}\n原文>>>`)
  if (input.guidance !== null && input.guidance.trim().length > 0) {
    lines.push(`\n用户要求：${input.guidance.trim()}`)
  }
  return [
    { role: 'system', content: SYSTEM },
    { role: 'user', content: lines.join('\n') },
  ]
}
```

```ts
export async function rewriteSceneSeg(opts: RewriteSceneSegOptions) {
  const { root } = getContext()
  const scene = await readSceneFile(root, opts.chapterNo, opts.sceneNo, opts.version)
  if (scene === null) throw new InkloomError('NOT_FOUND', `…版本文件不存在`)

  // 已定稿：正文不可再变（spec §4.19）
  const chapter = await getContext().db.chapter.findFirst({
    where: { chapterNo: opts.chapterNo },
  })
  if (chapter?.status === 'finalized') {
    throw new InkloomError('CONFLICT', `第 ${opts.chapterNo} 章已定稿，先 unfinalize 再重写`)
  }

  const idx = scene.segments.findIndex((s) => s.segId === opts.segId)
  if (idx < 0) throw new InkloomError('NOT_FOUND', `…没有段 ${opts.segId}`)

  const blueprint = await readJsonElement(root, `story/blueprints/ch-${pad3(opts.chapterNo)}.json`)
  const messages = buildRewriteMessages({ …前后段/原文/蓝图/guidance… })

  const r = await chat({
    apiKey: opts.apiKey,
    model: opts.model ?? 'deepseek-flash',
    messages,
    // 段一般 100–400 字；×4 再留 1024 给推理模型思考
    maxTokens: Math.ceil(countWords(original) * 4) + 1024,
    ...(opts.fetchImpl === undefined ? {} : { fetchImpl: opts.fetchImpl }),
  })

  const verdict = sanitizeRewrittenSegment(r.content, original)
  if (!verdict.ok) throw new InkloomError('INVALID_INPUT', REASON_TEXT[verdict.reason])

  const { newVersion, relPath } = await editSceneSeg({
    chapterNo: opts.chapterNo, sceneNo: opts.sceneNo, version: opts.version,
    segId: opts.segId, newText: verdict.text,
  })
  return { newVersion, relPath, original, rewritten: verdict.text }
}
```
